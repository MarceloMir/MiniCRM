# MiniCRM

Sistema de gestión de información comercial desarrollado como proyecto académico de Ingeniería en Software.

## Descripción

MiniCRM permite administrar la información que alimentará el Core del sistema, facilitando la organización de clientes, usuarios, productos, campañas y catálogos comerciales.

## Módulos administrativos

- Usuarios y roles.
- Clientes y segmentos.
- Productos y categorías.
- Campañas.
- Situaciones comerciales.
- Acciones comerciales.

## Tecnologías utilizadas

- ASP.NET Web Forms
- VB.NET
- .NET Framework 4.8
- SQL Server
- Visual Studio 2022
- Git y GitHub

## Requisitos

- Visual Studio 2022.
- .NET Framework 4.8.
- SQL Server y SQL Server Management Studio.

## Configuración

1. Clonar el repositorio.
2. Abrir la solución `.sln` en Visual Studio 2022.
3. Crear la base de datos `MiniCRM_DB` en SQL Server.
4. Ejecutar los scripts SQL del proyecto para crear las tablas y procedimientos almacenados.
5. Configurar la cadena de conexión en `Web.config`.
6. Ejecutar el proyecto desde Visual Studio.

## Seguridad

El sistema incluye validación de cédula en el Back-End y controles de acceso según el rol del usuario.
